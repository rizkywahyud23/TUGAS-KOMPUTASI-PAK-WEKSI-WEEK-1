## Deskripsi

Repository ini berisi tugas pada minggu pertama perkuliahan *Komputasi Statistika* di semester 3 Program Studi Statistika.

Tugas ini dibuat sebagai latihan untuk memahami dan menerapkan beberapa struktur data dasar menggunakan bahasa pemrograman *R*. Struktur data yang digunakan meliputi vector, matrix, array, data frame, dan list.

Melalui tugas ini, saya mencoba memahami cara membuat, menyimpan, dan menampilkan berbagai jenis data di dalam R sebagai dasar untuk kegiatan komputasi dan pengolahan data pada perkuliahan Statistika.

---

## Materi yang Dikerjakan

Pada tugas ini terdapat beberapa struktur data yang dibuat, yaitu:

1. *Vector*

   * Vector numeric
   * Vector integer
   * Vector logical

2. *Matrix*

3. *Array*

4. *Data Frame*

   * Kolom character
   * Kolom numeric
   * Kolom integer
   * Kolom logical

5. *List*

   * Berisi beberapa jenis struktur data seperti vector, matrix, array, dan data frame.
   * Terdapat juga list yang berada di dalam list utama.
